日期：2026-09-28

发布分支：`main`（候选分支 `codex/v0.18.1-stabilization` 已快进合入）

## 目标

收束 `0.18.0` 发布后发现的 Windows CI、文档和默认分支债务，不扩展产品功能：

1. 修复 `eval:smoke` 在 Windows 清理本次评测临时目录时的短暂 `EBUSY`。
2. 修复 launcher 覆盖后台 worker 已写入终态的竞态。
3. 修复无 Git 工作区扫描对 Windows Junction 的目录项差异。
4. 将 `csv-parse` 升级到包含 GHSA-8cw4-87c7-c6xx 修复的 `7.0.3`。
5. 统一版本、README、使用/发布说明、CHANGELOG、路线图、设计稿和发布状态。

## 安全边界

- 临时目录清理只接受 `evals/results/.tmp` 下本次创建且带精确前缀的目录。
- Windows 短暂占用仅做 8 次、100ms 递增等待的有界重试；持续失败仍让门禁失败并保留错误。
- 不强删旧评测结果，不移动或覆盖 `v0.18.0` 标签。
- 未启动真实模型或新付费调用，未扩大工作区、Skill、MCP、插件或子 Agent 权限。
