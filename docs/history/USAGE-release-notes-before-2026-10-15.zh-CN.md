### 模型管理与聊天选择（0.20.8）

打开「设置 → 模型与渠道」即可在当前页新增、编辑或删除渠道，配置凭据、刷新模型、测试连接及视觉能力；不再点击跳转按钮或另开管理弹窗。聊天窗口模型菜单仅选择已有渠道及模型，不含编辑、凭据或测试入口。设置内切换对话模型不会关闭本页；切换分类或关闭设置会清空未保存的凭据输入，取消在途视觉测试。仍需先打开可信工作区，运行中不能重配，Plan 与视觉计费独立确认不变。

视觉批量检测（0.20.8 本地候选）：先在渠道中“刷新模型”，再点“测试全部视觉候选”。测试当前渠道列表中的全部视觉候选，包含未知能力对话模型，不跨渠道。确认框一次展示数量、清单、地址与可能费用；每个模型最多一次请求，串行测试，显示完成数量和逐项结果，可取消剩余检测。超过 200 个候选会提示先整理列表，不会静默只测一部分。仍保留单模型与手填 ID 测试；不自动择优或切换已选模型。

### 视觉能力实测（0.20.8）

在模型管理中点击“测试视觉能力（可能计费）”；编辑已保存渠道时，可先选择候选或手填视觉模型 ID 再测试。地址和凭据使用已保存配置，其他修改需先保存。确认框会显示准确渠道、模型和地址；只发送内置随机数字图，不使用用户截图。每次确认只发起一次请求，不自动重试，60 秒超时，可取消（已发送请求仍可能计费）。结果为通过、测试未通过、无法确认或取消；仅本次展示，不是永久能力标签、电脑操作授权或任务验收。网络错误和不符合格式的回答不等于不支持视觉。Plan 模式及任务运行时不能测试。

视觉候选选择（0.20.8 本地候选，未发布）：刷新模型后，视觉列表同时保留能力未知的对话模型。编辑渠道里的独立候选菜单不按当前输入值过滤；也可手动填写任意合法模型 ID。候选标注「接口声明支持视觉」「名称推测，未验证」「能力未知，未验证」；声明或推测不是实测通过。明确的图片输入元数据归视觉、图片输出归生图；未明确输入/输出的模态仅保留候选提示。编辑中的刷新针对已保存渠道，不应用未保存的地址或凭据。切换视觉模型后仍须重新确认电脑截图的发送范围，普通「测试连接」不等于视觉测试。

截图发送模型：电脑操作使用渠道配置的视觉模型（`capabilities.vision`），未单独配置时回退到对话模型，并非固定内置模型。因此对话模型和确认框里的截图模型可以不同；确认框显示实际视觉模型及发送地址。可在模型与渠道配置中调整视觉模型，改变发送范围后需重新确认。

电脑人工验收与编辑（本地候选，未发布）：程序「未验证」不等于操作失败。任务结束后，在本轮「电脑操作结果」点击「我确认结果通过」或「结果未通过」，独立确认后保存；不会覆盖程序失败、校验或风险提醒，也不会让下一轮继承。Plan 或其他任务运行中不可记录。自动授权范围内，改写当前行可使用 End → 观察 → Shift+Home → 观察 → 一次输入替换；Shift+Home / Shift+End 仅用于非敏感 Edit/Document 控件，自动换行时可能选中视觉行，须检查选区。手动逐步授权会切走焦点，不适合连续选区编辑。任意系统组合键和剪贴板仍未开放。

电脑交互候选（2026-10-12，未发布）：新版完全访问确认明确列出当前视觉渠道、模型与发送目的地，以及前台窗口操作。接受后，同一工作区和渠道的普通任务不再重复确认目标；重开/重配清除授权，旧授权或不同渠道仍询问。目标由模型发现后自动切到前台；系统拒绝切换时不会发送输入。悬浮条显示实际观察、分析、操作和等待阶段，提供暂停/继续/停止。暂停阻止下一次观察/输入，已经发出的动作可能仍在结束；授权计时和截图时效照常，继续后过期帧仍需重新观察。停止撤销目标并取消绑定任务。请勿同时使用鼠标键盘；本版不支持后台互不干扰操作。

动态界面增量（2026-10-12，未发布）：每次 `computer_input` 默认等待 350 毫秒并重新观察，不再要求模型额外填写验证问题。`verificationDelayMs` 与 `computer_observe.delayMs` 可设为 0–3000 毫秒整数，供动画或加载完成后观察；等待不操作电脑、不重放输入。截图已超过 60 秒时，视觉响应不再输出可用帧和控件 ID，需重新观察。取消等待不继续截图上传；已输入但反馈失败明确标为未验证。维护者报告记事本验收通过，不代表完整实玩或全部应用兼容性通过。

0.20.8 自动电脑操作本地候选（2026-10-09，未发布）：在「电脑操作」描述目标；用户显式启用本会话完全访问后，父 Agent 查找窗口并请求目标及实际视觉渠道的范围授权，然后循环观察、输入与验证。授权内不再逐步弹窗，控件 ID 优先、坐标补充；手动控制收进调试区。自动范围最长 20 分钟 / 100 次输入，单步仍 10 分钟 / 30 次。新帧 60 秒有效、每次输入消费，停止/任务结束/工作区或视觉渠道变化撤销；不重放未知输入。Plan、未信任工作区、CLI、子智能体不获此能力。只操作授权窗口，密码、支付、删除、发布等高风险流程不支持。真实付费模型与完整实玩验收尚未完成。

使用方式：打开待测试的普通应用，在右侧加号选择「电脑操作」，启用自动操作（通过既有完全访问确认），输入目标并开始任务。模型查找窗口，主进程再确认目标及视觉渠道范围；之后自行观察和输入，并展示最近截图及操作记录。也可直接在会话描述目标。手动截图、坐标/文本输入在「手动操作与调试」中。「停止并撤销」与 Ctrl + Alt + Backspace 随时可用（快捷键未被占用时）。遮挡、尺寸变化、修饰键按住、无焦点或失效截图会拒绝；失败不重放。管理员、终端、远程桌面、密码管理器、系统设置、密码/登录/支付/验证码窗口不支持，视觉描述不代表确定性测试通过。程序读不到目标控件（例如没有名称的图标按钮、画布应用或跨进程焦点）时，即使在自动模式下也会单独弹窗询问这一步是否执行；截图结果会注明控件信息是否完整。授权框会说明控件名称和视觉描述会返回对话模型并写入会话历史。

## 0.20.7 任务审查修复（2026-10-08）

以下行为已发布到 GitHub 0.20.7，不在旧版 0.20.6 安装器内。main Windows 测试有一项已接受但未修复的后台竞态，非全绿发布，详见发布指南；npm 尚待认证：

- 文本增删统计独立于 16 KiB Diff 预览保存；分块比较跳过未变化的中间内容，大段替换也保留增删两侧。计算工作量超限时标为估算，二进制/过大文件仍受原读取边界限制。旧历史没有独立计数时优先使用已保存区段头的行数估算，缺少区段头则仅数可见行，均明确标为受限统计，不用当前文件补造。
- 当前会话的附件卡按具体用户消息绑定，包括运行中的补充消息；后续轮次上传的图片不显示在前一轮。重新打开历史会话时，从原消息的 `.xiu/attachments` 引用恢复本地上传缩略图；缺失或不可读的文件保留提示，不会静默消失。继续历史会话后仍保留附件归属；不新增图片正文到运行账本，不从历史文本读取任意路径或联网下载。
- 新记录保存完整脱敏文本 Diff，侧栏和审查弹窗每页 250 行，支持翻页及直达末页，长行横向滚动、不省略后半段。原安全读取限制仍有效（文本快照单文件 256 KiB、总量 8 MiB；持久化 Diff 单文件 2 MiB、总量约 32 MiB），二进制或超限项明确说明。旧记录只有预览时明确显示“不可恢复”和范围估算，不读取当前文件冒充当时完整版本。
- 失败结果显示程序验收结论及仍未通过或因文件修改失效的校验分类、数量；模型回复保留但不代表验收通过。计划全部完成不再等同于验收成功；不降低必需校验门禁。
- 非 Git 目录禁用“工作区 / 已暂存”，说明它们需要 HEAD / 暂存区基线；“本任务”仍比较任务起点与当前文件。不自动创建仓库或暂存文件。

## 0.20.6：桌面设置中心（2026-10-04）

深色补修：工作区顶栏、检查器标签栏及半透明弹层采用深色表面；子智能体六组身份配色使用哑光深底与彩色图案，不使用亮色渐变或纯白状态边框。此版本独立打包，不替换旧版正式发布资产；按维护者要求跳过本次远端 CI，验证范围见发布指南。

左下角「设置」打开独立设置页，分为外观、对话与运行、通知、模型与渠道、关于。外观支持跟随系统、浅色、深色，界面/代码字号、舒适/紧凑布局和减少动画；立即生效并保存在本机，重启保留。对话设置包括自动跟随、运行过程/提醒默认展开和 Enter 或 Ctrl/⌘+Enter 发送；输入法确认不提交，Shift+Enter 始终换行。关闭自动跟随后，「回到最新进展」仅跳到底部，不重新启用持续跟随。

通知默认关闭，仅在窗口不在前台时提醒完成、失败或需要批准；通知不含需求、路径、代码或回复。提示音由操作系统处理。模型与渠道沿用既有配置入口；完全访问不会保存为偏好，Plan、信任和审批边界不变。

本批不提供图形化超时配置或自动更新检查。「对话与运行 → 高级」说明现有 600/180/900 秒等待及启动环境变量；「关于」显示真实版本与构建类型。0.20.6 Windows 安装器直接保存在 `apps/desktop/release`，解包目录为 `apps/desktop/release/win-unpacked`，仍未签名；旧本地设置候选不冒充本版资产。

最新本地视觉优化：过程用轻量的“运行记录 · N 条事件”入口，不把事件数量当成工具操作数量；去掉嵌套蓝色进展卡和没有实际进展的重复占位说明，完整事件仍可展开查看。历史标题单行省略，完整需求保留在对话中；中性背景、紧凑顶栏与轻量底部状态降低视觉拥挤，“回到最新进展”浮在输出区，不额外挤占输入区。审批、停止、恢复和权限入口不变。

最新本地阶段摘要：提交时不把用户输入复制到任务概览；有计划或公开进展后显示目标、阶段与进展，结束后改为结果摘要。摘要限制长度，普通工具日志和接收片段不会反复更新时间，不额外调用模型。详细需求、完整输出和待验收项仍保留在对话记录中。

最新本地跟随补修：输出与布局变高时自动跟随到底部；手动上翻暂停跟随，点击“回到最新进展”恢复。子智能体使用八种稳定矢量图案、身份配色和状态点。流式超时只新增记录片段数、正文/参数字符数与超时阶段，不记录残缺参数或隐藏思考；超时后的下一次手动继续同模型任务改用完整响应模式（默认最多等待 900 秒），恢复该失败会话也保留此兼容方式。不会自动重放，也不能保证解决渠道停顿。

本地运行提醒补修：警告默认折叠成一行，单项详情按纯文本展示并限高滚动，不遮住最新进展；历史错误不会被删掉。公开回复的安全完整行实时展示，工具参数只展示接收字符数，必须完整校验后才执行，不展示隐藏思考。空的角色/用量响应片段不会把首次正文等待提前降到 180 秒；首次正文/参数默认等待 600 秒，有正文后新增片段停顿 180 秒，非流式完整响应 900 秒。正常等待仍在运行的子智能体不按重复调用拦截；已结束或反复失败的调用仍受保护。文件变更后的旧校验仍需重跑，完成检查会列出具体欠缺约束。

## 0.20.5 正式版

[GitHub 正式版](https://github.com/andrewjr1991/xiu/releases/tag/v0.20.5) 已发布，候选及 main 的六项 CI 均通过。下述本地补修行为已纳入 0.20.5。Windows 安装器仍未签名；npm 0.20.5 待登录认证后发布，当前 latest 为 0.20.4。旧版本发布待办仅为历史记录，最新制品与发布状态以发布指南顶部为准。

等待状态固定在输入框上方，不随过程区滚走或折叠。首次公开正文或工具参数等待默认 600 秒，正文开始后连续没有新增内容默认 180 秒，非流式完整响应等待默认 900 秒；新增正文或参数会刷新流式计时，空角色片段、用量片段和重复心跳不刷新正文计时，不限制整个回答总时长。超时不能证明模型没有生成或底层网络没传输，未完成工具不执行、不自动重试，仍可随时停止。可在启动 Xiu 前用环境变量 `XIU_MODEL_FIRST_RESPONSE_SECONDS`、`XIU_MODEL_STREAM_IDLE_SECONDS`、`XIU_MODEL_COMPLETE_SECONDS` 分别调整（正整数秒，最多 86400）；桌面设置面板暂未提供这些选项。查看计划请点击输入框上方计划条；工具摘要不再提示 `/tasks`。

手动删除会话文件后，软件内确认删除仍可清理对应残留任务记录；重复删除不再报“任务不存在”。不会删除工作区游戏文件。流式响应缺少结束标记时，本次仍停止并保留已完成文件，不执行残缺工具；再次继续同一渠道/模型任务（包括重新打开历史任务）改用非流式请求，不自动重试或收费调用。非流式也缺少结束标记则继续失败关闭；渠道问题仍需真实复测。

真实贪吃蛇任务回归修复：追问保留前面各轮对话，切换模型保留当前会话上下文，但完全访问授权仍重置，历史审批不会恢复。右侧环境、变更和子任务只属于当前任务，不把旧结果当本轮结果。运行中的过程和步骤默认展开，可手动收起且不会被进度更新重新打开；结束后自动收起。步骤区使用有高度上限的计划弹层，不挤压输入框；同一失败的重复提醒合并显示。

新建空工作区先列文件，不应读取尚未创建的文件。进程参数只接受数组或有界、可解析的 JSON 数组字符串，不会把命令字符串按 Shell 执行；超限代码应先写入文件。`unknown` 结束状态会区分渠道缺少或不支持结束标记，不能据此断言是输出上限或轮数限制，未完成工具仍不执行；需要检查渠道或换模型复测。

模型派发子智能体不再设置任意十轮或三轮预算，默认没有轮数上限；用户显式 CLI/环境预算仍有效。等待时区分尚无响应与正在接收输出，工具参数流也计入进展。采用上文首次响应/流式停顿/完整响应三段超时；持续返回可解析片段的长生成不按三分钟截断。未完整结束的模型响应仍失败关闭，不执行未完成的工具调用，也不自动重放写入。遇到补丁原文不匹配，整批不写入，并提示重新读取当前文件。
