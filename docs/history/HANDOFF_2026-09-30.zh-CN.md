## 5. 当前唯一最高优先级缺口

### 现象

实时任务右侧“变更”能显示当前任务 Diff；打开历史任务后，会话、工具过程和计划可以恢复，但右侧历史 Diff 为空，也没有类似 Codex 的“本任务修改了 N 个文件、+A/-D”摘要卡。

### 根因

- `DesktopTaskHistorySnapshot` 目前只返回任务元数据、会话 entries、runtime events 和 fidelity，没有历史 `TaskChangeReport`。
- `TaskController.openTaskHistory()` 只重建会话和运行事件。
- 当前变更是用内存中的任务起点 `baseline` 与工作区现状即时计算；任务完成后没有保存可供历史视图读取的受限变更报告。
- `TaskChangeSnapshot` 明确是临时对象，不能序列化；可以持久化的是经过边界限制和脱敏后的 `TaskChangeReport`。

### 期望结果

1. 任务完成时保存该任务的有界、已脱敏变更报告。
2. 打开历史任务时加载对应报告。
3. 会话中显示紧凑的 Codex 风格变更摘要卡。
4. 右侧“变更 / 本任务”自动展示历史任务的 Diff，而不是当前工作区的实时 Diff。
5. 删除任务时同时删除其历史变更快照。
6. 老任务没有快照时保持兼容，明确显示“该历史任务没有保存变更快照”，不能伪造 Diff。

## 6. 推荐实现方案

### 6.1 新增历史变更存储模块

建议新增 `src/task-change-history.ts`，提供：

```ts
saveTaskChangeHistory(workspace, runId, report)
loadTaskChangeHistory(workspace, runId)
deleteTaskChangeHistory(workspace, runId)
```

存储位置：

```text
<workspace>/.xiu/task-change-history/<runId>.json
```

要求：

- 使用版本化 envelope（例如 `schemaVersion: 1`）。
- `runId` 仅允许 `/^[A-Za-z0-9-]{1,160}$/`。
- 路径必须是安全的工作区相对路径，拒绝绝对路径、`..` 和 `.xiu` 内容路径。
- 对报告再次执行 secret redaction。
- 限制文件数、单项 preview 长度和总文件大小（参考：最多 500 个文件、单 preview 16 KB、总计不超过 1 MB）。
- 使用临时文件 + rename 原子写入。
- 拒绝把符号链接当作存储目录或目标文件。
- 只保存 `TaskChangeReport`，绝不保存临时 `TaskChangeSnapshot`、原始二进制内容、凭证或隐藏推理。

### 6.2 接入任务完成生命周期

文件：`apps/desktop/main/task-controller.ts`

- 在收到 `task.finished` 时，立即捕获当前 `workspace`、`baseline` 和最新 run。
- 使用 `inspectTaskChanges(workspace, baseline)` 生成最终 `TaskChangeReport` 并持久化到该 run ID。
- 与现有 `saveRuntimeEvents` 一起完成，但不要让下一任务覆盖本任务的 baseline 引用。
- 清理 baseline 时仅在引用仍属于本任务时清理，避免快速连续任务竞态。

### 6.3 历史读取与删除

文件：`apps/desktop/main/task-controller.ts`

- `openTaskHistory()` 找到所选 session 的运行记录后，从新存储加载 change report。
- 如果一个 session 有多次 run，从新到旧找到最近一份可用快照。
- 在返回值中加入 `changes`。
- `deleteTask()` 删除该 session 相关 run 时，同时删除各 run 的历史变更文件。

### 6.4 扩展桌面协议

文件：`apps/desktop/shared/protocol.ts`

给 `DesktopTaskHistorySnapshot` 增加：

```ts
changes?: TaskChangeReport;
```

使用可选字段，保证旧数据和旧任务兼容。

### 6.5 历史界面展示

文件：`apps/desktop/renderer/src/App.tsx`

- 在历史会话顶部或结尾添加 `ChangeSummaryCard`：显示文件数、总 `+/-`、前 3 个文件，支持展开全部文件。
- 增删行数可从 preview 行的 `+` / `-` 统计；统计不完整时展示限制提示，不伪装为精确值。
- 打开历史任务时自动选择右侧 `changes` 页、`task` 视图，并清理此前文件预览。
- `historyView?.changes` 存在时，“本任务”视图使用历史报告；切换到“工作区/已暂存”时仍显示当前工作区状态。
- 历史快照缺失时显示兼容提示，不回退成当前实时变更。

### 6.6 样式

文件：`apps/desktop/renderer/src/styles.css`

- 复用现有浅蓝/灰白体系。
- 变更摘要保持紧凑，新增绿色、删除红色、hunk 蓝色。
- 不新增巨型弹窗或大字号，保持与当前紧凑布局一致。
