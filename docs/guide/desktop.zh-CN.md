## 桌面开发预览（v0.20.0 G5C）

桌面端目前是独立开发预览，不随已发布的 `@xiu-ai/cli` 安装。桌面开发、构建和打包要求 Node.js 22.12.0 或更高版本；已发布 CLI 的运行基线仍为 Node.js 20.18.1，两套 CI 矩阵分别验证各自基线。开发运行：

```powershell
npm --prefix apps/desktop ci
npm run desktop:build
npm run desktop:smoke
npm run desktop:smoke:ui
npm run desktop:installer:win
npm run desktop:smoke:installer:win
npm run desktop:installer:msix:win
npm run desktop:smoke:installer:msix:win
```

`desktop:installer:win` 在 `apps/desktop/release/` 生成 Windows x64 辅助安装器；默认按当前用户安装，不要求提权，不自动创建桌面快捷方式，卸载时保留用户数据。`desktop:smoke:installer:win` 使用隔离的应用数据目录和含空格、中文的安装路径，自动验证全新安装、安装后 `Xiu.exe` 的 Electron fuses（RunAsNode、NODE_OPTIONS、`--inspect` 关闭；Cookie 加密、ASAR 完整性校验、仅从 ASAR 加载开启）、安装物启动、覆盖升级、异常中断后重启和静默卸载。`desktop:smoke:ui` 使用不进入正式包的测试桥驱动真实 Renderer，覆盖 1366×768、900px 窄窗、键盘提交、Provider/模型、审批、30 轮事件流、停止、未知副作用门禁、检查点还原和终端生命周期。

`desktop:installer:msix:win` 同目录生成 Windows x64 `.msix`，`desktop:smoke:installer:msix:win` 使用 Windows SDK `MakeAppx.exe` 解包并核验包身份、x64/full-trust 清单、主程序和块映射。MSIX 与 NSIS 的签名要求不同：Windows 正常部署要求 MSIX 使用目标设备信任的代码签名证书，或交由 Microsoft Store 签名。构建机没有发布证书时只生成待签名候选，不能把结构 smoke 误报为可直接安装；发布/企业分发时通过 electron-builder 支持的 `CSC_LINK` 与 `CSC_KEY_PASSWORD` 注入证书，私钥和密码不得写入仓库、日志或产物目录。

打开目录后必须先显式信任工作区。信任后可创建真实 Agent 任务、查看流式进度和计划、补充要求、停止任务，并对写入、执行和危险操作进行仅本次审批；核心提供精确且非危险的权限范围时，还可选择“本次会话始终允许”。已发布 0.20.1 的输入框底部另有三个由主进程实施的权限模式（0.20.2 候选以本文开头新模式说明为准）：“每次询问”保持逐次审批；“工作区自动”仅自动批准工作区文件写入、编辑和项目验证；“高权限”自动批准非危险操作。权限模式只能在任务空闲时切换，退出应用后恢复“每次询问”；危险操作、工作区信任和路径边界在任何模式下都不会自动放行。若 CLI 或另一个 GUI 任务持有工作区写锁，桌面端会阻止新任务；应先在原进程停止任务，再重新打开工作区，不会强制抢锁。

“最近任务”会载入脱敏、有界的历史记录，并可直接在输入框中继续对话；Xiu 会恢复对应 Provider 会话，但不会重新执行历史工具。完成的新任务会把同一条有界运行事件流写入任务账本，并把最终的有界、二次脱敏 `TaskChangeReport` 独立保存到工作区 `.xiu/task-change-history/<runId>.json`；通用任务账本和安全审计日志不包含源码 Diff。当前任务完成时，会话尾部立即显示文件数、总 `+/-` 和逐文件统计的变更摘要卡；历史会话载入同一张卡。展开文件列表并点击文件会打开保存的有界 Diff，右侧“变更 / 本任务”也读取同一份报告；切换“工作区”或“已暂存”仍读取当前状态。旧任务如果没有快照会明确提示，不会用当前工作区 Diff 冒充历史；旧过程也只会依据仍存在的会话和任务账本重建可证实的模型轮次、工具、检查点及结果，缺失事件不会被伪造。侧栏悬停后可删除任务；应用内确认卡说明影响范围，主进程仍会校验显式确认后再删除该会话、续聊运行记录及对应变更快照，但保留项目文件与检查点，运行中的任务不能删除。“最近项目”的移除使用同一套应用内确认，只清理列表记录，绝不删除磁盘目录。“新建任务”会清空当前对话、运行事件和会话级审批范围。输入框左下角的“＋”可选择文件或图片，也可直接粘贴或拖入；附件会在数量和大小门禁内复制到当前工作区的 `.xiu/attachments`，并在输入区显示文件卡片或有界图片缩略图，内部工作区引用只随请求发送，不再作为正文暴露。

过程区域按模型轮次呈现进展、工具活动、工作区变化和验证门禁。Provider 返回的用户可见说明标为“公开思考摘要”；只有工具调用、没有公开文本的轮次则标为“模型进展 / 可核验运行事实”，内容仅从计划、工具描述、文件变化和验证事件归纳，不推测模型内部原因。界面不会请求、保存、伪造或显示模型私有思维链。

输入框下方的 Provider/模型入口会读取与 CLI 相同的注册表，并使用剩余宽度显示完整模型标识（极窄窗口仍可通过悬停标题查看全名）。当前 Provider 固定置顶；其他渠道只有存在真实凭据或曾成功发现并持久化模型目录时才显示，未连接过的免 Key 本地预设也会隐藏。可以选择 Provider、按需刷新其模型、测试连接并明确选择对话模型；内置和自定义渠道都会按“对话、视觉、生图、视频、音频”分组显示已启用能力的模型，点击能力模型会持久化该渠道的独立选择。自定义渠道还可以手工填写供应商模型 ID。媒体模型不会混进对话模型列表。每个 Provider 的已发现模型目录分别缓存到用户目录的非秘密桌面缓存中；刷新一个 Provider 不会清空其他 Provider，重启桌面后也会恢复已成功发现的目录。Provider 或模型切换只影响之后创建的任务；任务运行中或存在外部写入者时禁止重配。桌面 Agent 会按声明注册图片分析、图片生成、视频生成和音频生成工具；所有可能计费的生成仍走危险审批与媒体幂等账本。生成的小型图片、音频和视频可在“文件”页内嵌预览，超过上限时只显示有界提示。桌面只显示凭据来源（环境变量、系统凭据、兼容文件、缺失或无需 Key），不会把已保存 Key 或 Base URL 发给 Renderer。配置新 Key 时，明文只经窄 IPC 送到主进程，并且只有 Windows Credential Manager 可用时才保存；系统凭据后端不可用会失败关闭，不会静默降级写入明文文件。环境变量来源的 Key 也不能从桌面覆盖。

右侧检查器提供变更、文件、终端、子智能体、数据和证据视图：

- 独立 Diff 提供目录树、文件搜索、行号与增删预览计数。执行轮次对应用户任务运行，不是模型内部调用次数；无快照轮次不读取当前文件替代历史。计数不包含省略的行。
- 子智能体显示真实角色、状态、耗时、进展和有界结果，会话中同时显示任务卡。父任务结束或关闭会取消并等待剩余子任务；子任务保持工作区边界，整合始终要求审查/测试证据和单独确认。

本地 0.20.4 开发候选（尚未正式发布）：会话按时间显示子任务派发、开始与终态，进度更新不会反复显示“开始”；点击状态行打开右侧子智能体列表，结果默认折叠。运行中的当前子任务可点“取消子任务”，需要独立弹窗确认；取消不撤销文件修改、不删除 Worktree、不自动重试，依赖任务可能被阻塞。Plan 模式禁止取消，历史任务仅展示保存的状态和耗时，不提供取消或自动续做。

本地模型切换修正：关闭并重新打开模型选择器会重新读取配置，核对后再明确选择模型，不自动重试上次失败的保存。恢复过 Provider 配置的客户端仍必须退出重启；活动/中断配置锁、文件安全检查及企业策略失败不会被重新读取绕过。左右任务视图保持同一数据来源，不把旧历史和当前子任务混在一起。

Windows 渠道配置权限（main，未发布）：保存渠道不再启动 PowerShell 校验或修改 `~/.xiu` 下配置文件和恢复目录的 ACL，只依赖 Windows 用户目录的默认权限（与 git、npm、ssh 的凭据文件相同）。受限语言模式（ConstrainedLanguage）、以管理员身份运行的终端和域策略不再导致“Provider configuration storage is not a protected regular file/directory”。POSIX 仍要求 0600/0700。
- 数据分别呈现持久后台进程、工具、本次新增/修改文件产出、来源读取调用和验证证据。历史任务不混入当前工具或验证；交互终端不能充当完成证据。

后台命令与 npm/npx MCP 需要本机 Node.js，桌面通过 PATH/NVM 解析，不使用 Electron 主程序充当 Node。找不到程序时显示修复提示，不自动安装 Node 或改写配置。修复用户 PATH 后需重新打开终端和 Xiu。

- “变更”可切换当前任务、整个工作区和暂存区。运行中的任务基线只存在于当前桌面进程；任务结束后只持久化最多 500 个文件、单项 preview 最多 16 KiB、总文件最多 1 MiB 的脱敏报告，不保存临时 baseline、原始二进制、凭证或隐藏推理。历史“本任务”只读取这份报告；没有报告时明确提示，不会回退为工作区变化。
- “文件”只列出有界、允许预览的工作区文件。绝对路径、路径穿越、符号链接/目录联接、凭证类文件、依赖与内部状态目录会被拒绝；文本、图片和总列表均有限额。
- “终端”提供直接由用户控制的交互式 Shell。PTY 只在主进程创建并固定绑定当前可信工作区，Renderer 只能按当前会话发送输入、尺寸和关闭请求。任务运行或外部写锁存在时不能启动终端；终端运行时也不能启动或恢复 Agent 任务。单次输入、输出分片、待发送队列和内存回放都有上限；切换工作区、关闭窗口或退出应用会结束子进程。终端输入不经过 Agent 审批，输出不持久化、不进入任务审计，也不能作为 Agent 验证证据。终端默认不继承名称含 `API_KEY`、`TOKEN`、`SECRET`、`PASSWORD`、`AUTHORIZATION`、`_AUTH` 等的环境变量和已配置渠道的 Key 变量，启动时在顶部用一行灰色文字列出被隐藏的名称（不显示值）；需要在终端里直接使用这些 Key 时，到「设置 › 对话与运行」关闭「终端隐藏凭据变量」，之后终端会提示它继承了哪些变量。该开关只影响你在终端里手动运行的命令，Agent 的命令工具不受影响。代理变量（`HTTPS_PROXY` 等）始终保留。
- “证据”汇总 Agent 命令的有界脱敏记录、验证、失败、检查点和中断恢复。检查点还原前由主进程原生确认，并先为受影响文件建立新的安全恢复点。

Markdown 原始 HTML 会先按文本处理；HTML 预览由主进程移除脚本、样式、表单、嵌入内容、远程资源和全部属性，再放入无权限 sandbox iframe。中断任务只有在运行记录与请求的 `runId` 精确匹配后才能继续或放弃；存在未知副作用时必须再次确认，恢复不会自动重放写入、命令或远端操作。

当前 G5C 已完成本机 Windows x64 NSIS 候选包、安装/覆盖升级/中断重启/卸载验收和自动化 UI smoke；未发布候选已接入 MCP、多 Agent 和后台任务。原生联网与插件仍待接入。先前 GitHub Actions 运行 `36691490514` 的六个作业通过，不代表本轮增量已在其他平台验收；Windows ARM64、企业策略设备以及 macOS/Linux 真实用户桌面尚未验收，仍显示预览标签。

### 工作台标签页（0.20.2 未发布候选）

右侧通过“＋”按需打开变更、文件、终端、子智能体、数据、证据或网页，标签右侧“×”关闭；右上角可切换完整视图/分屏。关闭终端页会结束当前交互终端，普通页签切换不会结束它。轮次、渠道类型和 MCP 等下拉菜单统一样式，支持方向键、Enter、Esc 和点击外部关闭。数据页默认显示名称、状态、耗时，点击条目再看已保存详情；来源仍是读取调用记录，不表示外部内容可信。

网页页签目前只有一个独立临时会话，手动输入公开 HTTPS 网址，支持后退、前进、刷新；不支持 HTTP、本地地址、登录提交、下载或弹出窗口。网页没有 Xiu 任务桥接、Node 或渠道凭据，内容不会自动进入任务上下文或验证证据。关闭页签结束网页并清理临时会话；网页不可覆盖应用内确认弹窗。这不是 Agent 原生联网检索，后者仍待接入。

### Windows 配置恢复目录初始化限制

此前版本在首次 Windows ACL 初始化失败后会留下一个空的、未加保护的恢复目录，并在之后一直拒绝它。现在 Windows 不再检查 ACL，旧版本留下的空目录可以直接使用，无需删除；非空的恢复目录可能包含原始配置备份，不要手动删除。
