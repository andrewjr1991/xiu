# 运行事件显示存储隔离 · 2026-11-07

状态：0.20.14 未发布候选；本轮处理晚到显示写入覆盖执行状态的交错。

## 问题与修复

原 saveRuntimeEvents 先读主记录，再加入 runtimeEvents 并原子替换整份主记录。若期间另一个实例已放弃、恢复或删除任务，晚到保存会撤销这些状态或重建已删除的记录。私有目录、两个 Journal 实例及可控 rename 交错的五项回归先失败，包含可选显示 IO 错误设置执行熔断的情况。

新保存只写 `<runId>.events`，格式为版本、工作区摘要、运行 ID 和显示事件。主记录格式不变；旧内嵌事件继续读取，新文件存在时优先使用它，不自动迁移或清理旧字段。

- 公共历史读取合并显示覆盖层；启动、恢复、放弃、人工结果元数据和主记录写入读取原始主记录，不能把显示字段反写执行状态。
- 显示文件最多 16 MiB/最近 1000 事件；读取使用有界缓冲、可用的 no-follow/nonblocking 标志、普通文件和前后身份/时间/大小检查。格式检查限于版本、绑定与基础事件信封，不宣称完整 payload 语义校验、真实性或旧工作区归属证明。
- 显示损坏或不可读取仍保留健康主记录，历史页明确提示重建。当前实例的显示保存失败使用有界内存标记；成功保存清除，重启不恢复该内存标记。错误不回显原始路径/内容，也不设置执行状态熔断。
- 精确删除先检查关联显示对象，非普通对象/权限错误停止；只删除原授权运行的文件，工作区内容和检查点保持。晚到写入可留下没有父记录的显示文件，但不能生成任务，不把孤立文件当运行记录，也不自动清理未知对象。

显示文件含用户可见会话文字，应按私有会话数据保管；创建权限 0600，调用方继续负责持久化前脱敏。显示事件与固定错误标记不能授予信任、审批、Plan、完全访问、人工验收或恢复权限。

## 验收与剩余边界

测试覆盖恢复/删除交错、活动任务拒绝、可选 IO 失败隔离、旧新读取、未来版本/错误绑定/畸形基础事件、超限、不安全对象、精确删除、内存提示恢复、伪权限字段忽略以及人工结果写入不引入覆盖层。实际桌面验收验证固定降级提示、原回复/附件/复制和续做；最低 Node 保持兼容。

旧客户端仍会使用旧写入方法，需配套升级；本轮不约束旧程序或外部直接改写。它不解决旧工作区摘要碰撞、所有权认证、底层路径替换或跨文件删除事务。完整锁协议和身份迁移继续按已有方案推进，不直接换摘要、删旧槽或重放未知操作。
